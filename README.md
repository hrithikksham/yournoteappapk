
# 📒 Yournote — Secure Notes App (Android)

Yournote is a **minimal, dark-themed secure notes mobile application** built to solve a personal problem: creating a fast, distraction-free notes app that prioritizes **privacy, performance, and simplicity**.

This application is currently available **only for Android** and is distributed as an **APK** (not via the Google Play Store).

---

## ✨ Features

- 🔐 Secure authentication using **JWT-based backend APIs**
- 🌙 Minimal **dark UI** designed for long, comfortable usage
- ⚡ Fast performance with optimized backend architecture
- 🗂️ Scales to **10,000+ notes per user** without lag
- 🔄 Reliable sync between mobile app and backend services
- 🧠 Clean separation of UI, authentication, and data layers

---

## 🛠️ Tech Stack

**Mobile**
- React Native (Expo)

**Backend**
- FastAPI (Python)
- JWT Authentication

**Database & Infra**
- MongoDB
- Redis (caching & state optimization)

## 📥 Download & Install (Android Only)

### 1️⃣ Download the APK

Download the latest APK from the link below:

👉 **[Download Yournote APK](#https://hrithikksham.github.io/yournoteappapk/)**  

---

### 2️⃣ Allow Special Permission (Required)

Since Yournote is **not installed from the Play Store**, Android requires a one-time permission.

1. Open **Settings** on your Android device  
2. Navigate to **Security** or **Privacy**  
3. Open **Install unknown apps**  
4. Allow permission for the browser or file manager used to download the APK  

> ⚠️ This permission is required **only for installation**.  
> Yournote does **not** request unnecessary device access.

---

### 3️⃣ Install & Launch

- Tap the downloaded APK file  
- Complete installation  
- Open **Yournote** and sign in

---

## 🔒 Permissions Used

Yournote follows a **privacy-first approach**.

**Required permissions:**
- 🌐 Internet access — for secure API communication and note synchronization

**Not used:**
- ❌ Contacts
- ❌ Media access
- ❌ Background tracking
- ❌ Unnecessary device permissions

## 💡 Why Yournote?

Most note-taking apps felt **cluttered, distracting, or visually heavy**.  
Yournote was built to be the opposite — **calm on the surface, powerful underneath**.

The goal is simple:
> A notes app that stays out of your way while being technically robust and secure.
